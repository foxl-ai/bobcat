\subsection{Provenance of the evaluated artifact}

The release manifest was frozen at 2026-09-25 02:40:42 UTC (commit \texttt{12942f9} of the
development history) before the final split was opened. The training code was at commit
\texttt{629a40c}. At freeze time the repository's test suite reported 752 passed and 4
skipped (the skipped tests need transformers, which the CPU node lacks, and ran on the GPU
host's preflight); passing tests is a structural check, not a quality result.
